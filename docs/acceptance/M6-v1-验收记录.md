## 用户可见灰盒专项

- 正式构建不渲染导航调试按钮或 F2 调试覆盖层；开发构建保留诊断能力。
- 场景人物均为水彩部件精灵；`Graphics` 仅用于灯光、点击涟漪、进度与杯子等程序效果，不承担占位形象。
- 地图、本店、海风分店、HUD、弹窗与图鉴均使用成品资产；未采用稿及一次性评审文件不入库。

## 红线与温柔化机制

| 专项 | 走查证据 | 结果 |
|---|---|:---:|
| 无失败态 / Game Over | 金币余额钳制为 0；金币与原料均空且基金无额度时可收下免费原料包继续经营 | ✅ |
| 无体力系统 | 配置、存档、HUD、经营状态与全仓文本检索均无体力值或行动次数 | ✅ |
| 无每日强制结算与排名 | 仅现实时间每日首摸礼物；无日结、连续签到、倒计时、过期奖励和排行榜 | ✅ |
| 缺货平静改点 | 首选缺货会改点有货饮品；全缺货文案为“改天再来”，离店无好感或金币惩罚 | ✅ |
| 梦想基金呈现 | UI 使用“前辈的支持 / 心意 / 还款罐”；明确零息、无期限，不出现强压金融措辞 | ✅ |
| 基金行为 | 多笔共存、总额度上限、消费不抬额度、按申请顺序存满还款罐 | ✅ |
| 冷落规则 | 未出杯订单释放全部预占；已出杯未上菜只消耗原料；无额外扣款或进度倒退 | ✅ |
| 碎片无登录压力 | 碎片仅换金币也能购买的普通款；无独占、连续签到加成或过期 | ✅ |

应急包裹、缺货与金币不足的玩家文案已统一为平静提示，不使用“失败”“检测到死局”等系统化措辞。
