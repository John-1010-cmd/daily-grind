## 目标

按设计文档第 15 节清单逐项验收，部署至 github.io，达到作品集可展示标准。

## 任务拆解

### T6.1 第 15 节清单逐项走查

- 验收条目以设计文档第 15 节为唯一出处（此处不复述，避免漂移）；逐项记录验证方式与结果
- 附加验收：**用户可见灰盒为零**——无占位矩形 / 占位形象 / 占位图标（对照 M3 T3.8 资产清单逐项核对）
- 完成标志：清单全绿

### T6.2 红线与温柔化机制专项走查

- 三条红线：任何操作序列无失败态（含"花光金币 + 耗尽原料"仍可领应急包裹继续经营）；无体力条；无每日强制结算与排名
- 两条温柔化机制：缺货平静改点（含全部缺货分支）；梦想基金（零息、多笔共存、总额度上限且消费不抬高额度、还款罐按申请先后清偿、应急原料包裹、UI 无"贷款"）行为与文案双查
- 冷落规则：不扣已有进度，仅损失该单机会收入与已消耗原料（第 5 节放弃规则）
- 每日登录压力检查：碎片无独占内容、无连续签到加成、无过期奖励（第 11 节）
- 完成标志：走查记录无违例

### T6.3 健壮性与性能预算

- 存档迁移：构造旧版本存档走 `migrate()` 路径，导入导出不炸；结构非法存档回退（M0 T0.10 覆盖项抽测）
- 长时间运行：挂机 + 多订单并发不掉帧、无内存泄漏（Pixi 显示对象按需复用）
- 触屏冒烟：手机横屏基础可玩（点地移动、面板响应式，第 13 节）
- **量化预算**（占位值，入 config 可调）：目标设备 = 中端笔记本 + 手机横屏；首屏资源体积 gzip ≤ 6MB；冷启动可交互 ≤ 5s（快 4G 模拟）；1080p 稳定 ≥ 50fps；触屏最小热区 44px
- 自动化：M0–M5 单元测试全绿 + 构建冒烟纳入 CI
- 完成标志：三项冒烟通过；量化预算逐项实测达标

### T6.4 部署 github.io

- 静态构建发布：base path、资源压缩、缓存策略；在 M0 最小 CI 基础上补 GitHub Pages 部署工作流
- 完成标志：公网链接可访问；冷启动可交互时间满足 T6.3 预算

### T6.5 收尾

- 复核第 17 节开放事项，更新 v2 backlog：其余 3 家分店 / 常客与店员扩充（含"托管店长"）/ 成就扩充 / 触屏深度适配 / 正式中文名 / 拉花涂鸦彩蛋 / 数值框架细化
- 完成标志：v2 清单成文
