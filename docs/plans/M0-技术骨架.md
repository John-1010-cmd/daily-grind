# M0 技术骨架 — 实施规划

> 对应设计文档：`docs/2026-09-12-daily-grind-design.md`（下称"设计文档"）
> 里程碑验收（设计文档第 16 节）：**页面跑起来，小人能走**
> 前置：无

## 目标

搭起可运行的最小技术骨架：仓库基座（git / CI / 测试）、渲染分层、灰盒场景、点地移动（含点击规则与导航图）、三时钟模块、光照 tint 空转、带版本号的存档。本里程碑不做任何玩法。

## 涉及设计章节

- 第 1 节：技术栈（TS + Vite + PixiJS + DOM/CSS）、存档决策（schema 版本号 M0 起生效）、操作（点地为主、WASD 为辅）
- 第 3 节：点击规则、预定义导航路径点、固定视角
- 第 10 节：三时钟模型（activePlayTime / wallClock / offlineElapsed）、光照四时段（M0 仅 tint 空转）
- 第 13 节：UI 用 DOM/CSS、场景用 PixiJS；HUD 布局

## 任务拆解

### T0.1 脚手架与仓库基座

- `git init` 并关联 GitHub remote（`gh repo create`，见 `docs/agents/issue-tracker.md` 顶部备注）；`.gitignore`、README（环境要求与常用命令）
- Vite + TypeScript 初始化；目录约定：`src/scene`（Pixi）/ `src/ui`（DOM）/ `src/save` / `src/config`
- **占位数值唯一出处**：一切占位数值（段长、价格、速率、比例）只进 `src/config`，不硬编码在逻辑里
- 版本固定：`package.json` 的 `engines`（Node LTS）与 `packageManager` 字段
- Vitest 测试基座（纯逻辑模块的单元测试，不渲染）
- GitHub Actions 最小 CI：push 时 typecheck + 单元测试 + 构建
- 完成标志：开发服务器可起（`npm run dev`），空白页可开；CI 绿

### T0.2 渲染分层与事件穿透

- Pixi 画布承载场景；DOM 覆盖层承载 HUD 与面板
- 指针事件规则：DOM 元素拦截自身事件，其余区域透传到画布（后续"万物皆可点"依赖此层正确）
- 完成标志：两层叠加渲染；点击 DOM 不触发场景点击，点击空白触发场景点击

### T0.3 灰盒场景

- 以 `style-reference.png` 构图为基准，用纯色矩形占位：门、吧台、桌椅 ×N、窗、猫垫
- 固定视角：设计分辨率 + 等比缩放（letterbox），不做镜头移动
- 完成标志：灰盒构图与母版布局一致

### T0.4 导航图与交互热区（设计文档第 3 节的 M0 硬性要求）

- 在母版上定义：可行走区域、导航路径点、每个可交互对象的交互点与热区（热区略大于视觉，触屏防误触）
- 数据结构落在 `src/config`（TS 常量或 JSON），与灰盒占位一一对应
- 调试开关：可视化显示路径点、可行走区、热区
- 完成标志：调试视图下导航图与母版吻合

### T0.5 点地移动与点击规则

- 店主占位方块；按设计文档第 3 节实现：对象优先于移动；点空地移动；点不可达 / 被遮挡对象自动移动至其交互点再触发；移动中再点即改目标
- 移动沿预定义导航路径点，不做实时 A*
- WASD 辅助移动（设计文档第 1 节：点地为主、WASD 为辅），与点击寻路共用速度与碰撞参数
- 完成标志：占位方块按全部规则走动，无卡死、无穿桌；WASD 可用

### T0.6 三时钟模块（设计文档第 10 节）

- 实现三个可注入时钟：`activePlayTime`（在线游玩累计时长，页面后台挂起时暂停计时）/ `wallClock`（现实本地时间）/ `offlineElapsed`（当前 wallClock − 存档时间戳，负值按 0 处理）
- 逻辑只消费注入值，测试可注入假时钟
- 完成标志：三个时钟可独立注入与快进；挂起暂停与时值回拨行为符合第 10 节

### T0.7 光照 tint 空转

- 四时段 tint 参数表（清晨冷光 / 午后暖光 / 黄昏 / 夜晚），由 `activePlayTime` 驱动循环；段长等参数入 `src/config`
- tint 作用于场景层全局；HUD 左上角时段图标占位联动
- 完成标志：tint 随时间流转，四时段可辨认

### T0.8 存档骨架（含版本化，设计文档第 1 节）

- localStorage 读写封装，自动存档（状态变更 + 节流）
- **页面隐藏 / 关闭（`visibilitychange` / `pagehide`）时立即落盘**，关键交易不丢
- save schema v1：`version` 字段 + `migrate()` 迁移入口（迁移表暂空）
- JSON 导入导出函数 + **设置面板占位**（DOM，HUD 右上"设置"按钮）：内含导入 / 导出入口与存档版本号展示——导入导出 UI 在此落地，不后补
- 完成标志：刷新后状态恢复；缺失 / 过旧 version 走迁移路径且不报错；导入导出在面板上可操作

### T0.9 HUD 占位

- 左上金币 + 时段图标（DOM），数值对接存档
- 右上一排图标按钮占位（配方 / 进货 / 装修 / 图鉴 / 分店地图 / 梦想基金 / 设置，设计文档第 13 节）：按钮排先行，面板随里程碑逐个点亮；M0 仅"设置"有面板（T0.8）
- 完成标志：金币数值改动即时反映；按钮排与第 13 节一致

### T0.10 存档测试

- 单元测试：存档解析、版本迁移路径、损坏 / 非法 JSON 回退（不炸、回默认值）、**合法 JSON 但结构非法**（字段类型错误 / 负金币 / 负库存）、未知或未来版本号、不存在的配方 / 家具 ID 引用、localStorage 写入失败（配额 / 隐私模式）降级不炸、`pagehide` 立即落盘、导入导出 round-trip
- 完成标志：Vitest 全绿并纳入 CI

## 红线自检

M0 不引入任何玩法机制；确认不夹带：失败判定、体力条、每日结算。
