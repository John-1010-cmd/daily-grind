# M2 美术管线首跑 — 实施规划

> 对应设计文档：`docs/2026-09-12-daily-grind-design.md`（下称"设计文档"）
> 里程碑验收（设计文档第 16 节）：**验证 AI 出图 + 程序合成管线可行**
> 前置：M1 完成（灰盒可玩）；美术量产在本里程碑之后（第 16 节原则）

## 目标

以最小集合跑通美术管线：本店空场景底图 + 店主部件图 + 橘猫，替换**对应**占位。本里程碑产出的是"管线证明"，不是全部资产——随机路人、饮品图标、UI 等其余灰盒允许保留（M3/M4 继续量产）。

## 涉及设计章节

- 第 14 节：量产管线（turnaround 参考图、场景分层、部件切分、gpt-image-review 工具与降级方案）
- 第 3 节：部件切割 + 程序补间动画；第 1 节：风格母版
- 第 11 节：橘猫睡姿是收集品（图鉴结构 M3 才做，本里程碑只产出素材与换睡姿逻辑）

## 任务拆解

### T2.1 管线基线（正式前置门禁）

- 确认本地 `gpt-image-review` skill 可用（gpt-image-2 出图 + k3-256k 审美评审）；**不可用时的降级方案**：改用现有 imagegen 类工具出图 + 人工评审，评审标准沿用本节沉淀的返工标准。本门禁不通过则后续任务不开工
- 以 `style-reference.png` 为风格锚点，沉淀：prompt 模板、评审记录、返工标准
- 完成标志：首张评审通过的图产出，流程可复现

### T2.2 资产规范先行

- 在生成首批资产**之前**定稿：`assets/` 目录结构、命名、尺寸与锚点约定、透明通道要求、运行时格式（WebP/PNG 与压缩策略）、单图与首屏体积预算
- 完成标志：规范成文；首批资产按规范产出并验证可用，M3 量产照此执行

### T2.3 本店空场景

- 空场景底图（无人、无可动物件）+ 物件纯色背景单件生成 + 程序抠图合成
- 分层约定：地面 / 墙面 / 前景遮挡层；与 M0 导航图对齐（物件落位 = 母版槽位）
- 完成标志：成品场景替换灰盒矩形，构图保持母版的插画家构图

### T2.4 店主角色

- turnaround 设定参考图 → 后续生成作 image reference 喂回（不靠裸 prompt 碰运气）
- 建议 A-pose（四肢微张）出图，便于头 / 身 / 双臂 / 双腿部件切割
- 完成标志：部件图全套，切口可拼接

### T2.5 程序补间动画

- 部件接入 M0 角色容器：走路 = 身体起伏 + 四肢摆动 + 轻微倾斜（纸偶感）；idle 小动作
- 完成标志：占位方块退役，店主以成品形象走动

### T2.6 橘猫素材与逻辑

- 睡姿图若干（收集品本体）+ 眯眼帧
- 随机换位置换睡姿逻辑（位置点取自 M0 导航图配置）
- 完成标志：猫在成品场景里随机出现、换睡姿（摸猫互动与音效在 M4）

## 红线自检

纯美术里程碑，无机制变动。

## 风险与对策

- AI 出图一致性不稳 → 降级：提高程序合成比例（统一色调 / 水彩纸纹理后处理），不追求 AI 直出成品（第 14 节已接受此路线）
- 抠图毛边 → 描边与纸纹理遮罩包容瑕疵

## 完成定义（DoD）

- 里程碑验收：管线可行——本店场景、店主、橘猫全部成品美术且过审美评审
- 上述三类指定占位替换完毕；其余灰盒（随机路人 / 饮品 / UI）允许保留
- 资产规范成文（T2.2）
