# Daily Grind

## Agent skills

### Issue tracker

Issues 托管在本仓库的 GitHub Issues（用 `gh` CLI 操作）。See `docs/agents/issue-tracker.md`.

### Triage labels

默认五个标准标签：`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：仓库根一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
